# NLP-Keyword-Extractor-MiniLM-KeyBERT
A professional, high-performance keyword extraction tool that uses KeyBERT and MiniLM (all-MiniLM-L6-v2) to extract contextual and semantic keyphrases from PDF documents. Features a streamlined UI built with Streamlit and employs MMR (Maximal Marginal Relevance) for diverse and accurate results.
